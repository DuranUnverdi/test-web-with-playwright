# test-web-with-playwright

Basit bir Playwright + Java test otomasyon projesi.

## Açıklama  
Bu proje, Playwright (Java) kullanarak web uygulamalarını otomatik test etmek için temel bir yapı sağlar.

## Yapı  
- `src/main/java`: Page Object Model sınıfları ve yardımcı yapılar  
- `src/test/java`: Test sınıfları  

## Gereksinimler  
- Java (tercihen 11+ veya projenin kullandığı versiyon)  
- Maven (veya build aracınız)  
- Playwright bağımlılığı (`com.microsoft.playwright`)
